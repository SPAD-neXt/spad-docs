# MSFS Specific Topics



## LVAR Bridge Outdated (MSFS 2020)

If SPAD.neXt keeps reporting that the LVAR Bridge is outdated:

1. Download the latest MSFS LVAR Bridge Installer at [https://www.spadnext.com/download/download-spad-next.html](https://www.spadnext.com/download/download-spad-next.html)
2. Proceed as follows
3. Exit MSFS 2020 and SPAD.
4. Delete any folders named "spad-bridge-module" in:

    MSFS Store/Xbox Version

    ```
    %LOCALAPPDATA%\Packages\Microsoft.FlightSimulator_8wekyb3d8bbwe\LocalState\Packages
    ```

    MSFS Steam Version

    ```
    %APPDATA%\Microsoft Flight Simulator\Packages
    ```
5. Delete any folders named "spad-bridge-module" in your Community folder.\
    Default locations:

    MSFS Store/Xbox Version

    ```
    %LOCALAPPDATA%\Packages\Microsoft.FlightSimulator_8wekyb3d8bbwe\LocalCache\Packages\Community
    ```

    MSFS Steam Version

    ```
    %APPDATA%\Microsoft Flight Simulator\Packages\Community
    ```
6. Install the latest version of the MSFS LVAR Bridge and select the MSFS 2020 location.
7. Start MSFS 2020 and wait until it reaches the main menu.
8. Start SPAD.neXt.

## LAG/FPS spikes with SPAD LVAR Bridge installed

During the first five minutes after starting a flight (after advancing beyond the Ready to Fly screen), the SPAD.neXt LVAR Bridge regularly scans for new LVARs. Depending on your system, you may notice lag spikes while it scans.\
You can adjust the scan parameters in SPAD.neXt under Settings → Application → MSFS.

| Name              | Purpose                                                               |                                                      |
| ----------------- | --------------------------------------------------------------------- | ---------------------------------------------------- |
| MaxLVarSearchTime | Time in minutes the bridge will scan for LVAR after flight is started | Increase it to look for LVAR longer                  |
| MaxDigBatch       | Number of LVARs scanned every frame                                    | Decrease the value to reduce the load on the simulator. |
| MaxDigDepth       | Maximum number of LVARs to search for                                  |                                                      |
|                   |                                                                       |                                                      |
