# General FAQ

## Can I use my license on another computer as well?

If you have a Complete Edition license, you can request a free secondary license by submitting a support ticket.&#x20;

If you have a Standard Edition license, deactivate it on the computer you are not using before activating it on the second computer. Otherwise, the license server may eventually blacklist it for license sharing.

## All my profiles are suddenly empty

Most likely your Documents folder got migrated to OneDrive by a Windows update.\
Possible solutions:

a) In SPAD.neXt head to Settings->Directories and alter the Documents-Folder to the new OneDrive folder

b) Move the SPAD.neXt-Folder back from OneDrive to the old location and keep profile local

## Does SPAD.neXt support device X?

If the device is listed in [Supported Hardware](../getting-started/supported-hardware/), it is supported. If it appears as a joystick in Windows' USB Game Controllers, it is supported as a generic joystick. You can enable or disable joystick support in Settings → Devices → Joysticks.

## Why does my Streamdeck show "not licensed" although it worked fine in trial?

Stream Deck support is a Complete Edition feature.\
You need to upgrade your license to the Complete Edition (Settings → Registration) or disable Stream Deck support (Settings → Devices → Elgato). The free trial includes the same features as a Complete Edition license.
