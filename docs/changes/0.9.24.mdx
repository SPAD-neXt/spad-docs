## 2026-03-28 0.9.24.26 Release

* X-Plane: Update Plugin to v6.12
* Devices WinCtrl: Add AGP Support
* Devices WinCtrl: Add ECAM Support
* Devices WinCtrl: Add PAC-32 Support
* Devices WinCtrl: Add PDC 3N/3M support
* Devices WinCtrl: Add support for URSA MINOR Joystick backlight and vibration control
* Devices Virtual-Fly: Add Compass support
* Devices Virtual-Fly: Add Switcho Trims led support
* Devices Wingflex: Add A320 FCU CUBE support
* Devices CPFlight: Add new MCP-Version support
* Devices Honeycomb: Add Sierra Gear led control
* Devices Elgato: Add Stream Deck XL+ support
* Devices VRInsight: Add uProPt support
* Devices Cockpit-Simulator: Add chained devices support (e.g. MCP/FCU + EFIS)
  * If you plan to use chained devices, do not chain them yet.
  * Start SPAD.neXt load the profiles where you have the "in future chained devices" programmed and save the profile again. (This will make sure you do not need to reprogram after chaining)
  * Exit SPAD.neXt, chain the devices (don't forget the 20V power supply!).
  * the FCU/MCP has to be Chainmaster (usb connected)
  * Start SPAD.neXt , have fun
* Devices Skalarki: Add DCDU Support
* GoFlight/OpenCockpits: relax interface stress
* MSFS24: Add Inibuilds A300/A340 CDU Support

* Expose LOCAL:SIM_PAUSE (0/1), LOCAL:SIM_PAUSE_EX1 , LOCAL:SIM_PAUSED (0/1) 
* SPAD Serial: Add UI.INACTIVE=1 to make an element non-interactable in spad ui
* SPAD Serial: Add VP.IMMUNE=1 to make an element immune to virtual power
* Add AudioControl action (External/Output->Audiocontrol)
* IScriptAction: Fix eventargs have wrong data. IScriptAction is now deprecated. use IScriptAction2 instead
* vFIP: Add button to reset vFIP window in case screen resolution/configuration changed
* UI: Data/Event search adds ";" as a multi-search delimiter
* UI: Data Monitor search adds ";" as a multi-search delimiter
* Fix aircraft assignments for P3d not loading
* Event UI: Add ordering of conditions
* RemoteCDUDisplay has been changed and requires an additional commandline parameter. To get it start it once from within spad, rightclick the display "copy cmdline" to copy it to the clipboard
* UI: Data Monitor add unit column
* UI: Device Rename is active immediately
* UI: Allow creation of subfolders when creating a new profile (use '/' in name)
* UI: Remember last selected device
* UI: Settings->General->UI Add option to automatically open edit dialog if only one action configured (Same as CTRL-E)
* UI: Settings->General->UI Add option to default new led actions to ON / AutoOff
* UI: Delay-Action: Add "SPAD common" static/data/expression for delay-time
* UI: Add button to Collapse/Expand device ui to gain more space for events
* UI: Visualize application shutdown
* UI: Enable Expression-dialog resizing
* UI: Enable online snippets without context
* X-Plane: Fix additional indexed datarefs not registered when already in use
* X-Plane: Dynamically discover all commands (XP12 only)
* X-Plane: Event monitor is working again (XP12 only)
* Axis Variable Unit can be configured per axis/device (Device Settings->Global)
  *   The default value is "Percent" which has been the current value. Possible values are

      Percent (0..100)
      \
      Raw value from device
      \
      Normalized (-16383 .. 16383)
      \
      AxisValue (0..1)
      \
      Inverted Raw value from device
      \
      Inverted Normalized (-16383 .. 16383)
  * For virtual devices (e.g. vJoy) it is recommended to set it to Raw value

You can switch rendering for ButtonGauges to the "future" device independent Skia renderer to prepare for Linux/Mac releases of SPAD.neXt in Settings->Application->Expert (Globally) or via a slider on the device (temporary) (No restart required,active instantly) Please report any major issues where buttons are rendered incorrectly&#x20;

Some slight render differences for textlayers **are expected**, specially if you defined a textbox that is too small to fit the text.

Please note that the vDeck base files have been changed, and if you get a "Unsupported connect" when opening the vDeck as webpage, please delete your customized html/css files (as well as the .disableUpdates) to have SPAD.neXt recreate them.
